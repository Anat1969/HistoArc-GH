# קוד העיר

מחולל עירוני תלת-ממדי שמבחין בין אבולוציה למהפכה בתכנון ערים.
קוד = (T, R, P, θ): סוגי אלמנטים, יחסים, כללי יצירה, וחמישה ערכים: סדר (O), עוצמה (FSI), סגירות (GSI), היררכיה (H) וגרעין (G).

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

`npm run build` מחשב מחדש את מטריצת השחזור (256 הרצות) ומריץ את שער העקביות לפני הבנייה.
